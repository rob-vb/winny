<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
    Full My Wins screen (app/(tabs)/wins.tsx) with:
    - HistoryHeroHeader: trophy + 64px gold total-wins number + "total wins" sub-label + streak label
    - SectionList with stickySectionHeadersEnabled showing wins grouped by date (newest section first)
    - DateSectionHeader for each date group: relative date label (Today/Yesterday/Mon May 9) + win-count pill badge + animated chevron
    - Collapse/expand per section: tapping header collapses/expands that day's wins independently
    - WinCard rows reused from Phase 2 (isNew={false}, no entrance animation)
    - Empty state: trophy + "Your wins will live here" + "Head to Home and log your first win."
  </what-built>

  <how-to-verify>
    Start the app: npx expo start --ios (or use your existing dev build)

    Navigate to the My Wins tab.

    **Success Criterion 1 — Wins grouped, newest first:**
    - All logged wins appear in the list
    - Newest date group is at the top
    - Confirm: the date shown in the top section header matches today or the most recent day you logged wins

    **Success Criterion 2 — Collapse/expand independence:**
    - Tap the top section header (e.g., "Today")
    - Confirm: that day's wins disappear; wins in other sections remain visible
    - Tap the same header again — wins reappear
    - Tap a different section header while another is collapsed — confirm only one day's wins collapse at a time (each section is independent)

    **Success Criterion 3 — Win count badge:**
    - Each section header shows a pill badge (e.g., "3 wins" or "1 win" singular)
    - Confirm singular form: if you have a day with exactly 1 win, the badge reads "1 win" (not "1 wins")

    **Success Criterion 4 — Total wins at top:**
    - Hero header is visible above the list with the large gold number
    - The number matches the total wins count you expect from your logged history
    - streakLabel line shows your current streak (e.g., "3 day streak!")

    **Bonus checks (flag if wrong, not blocking):**
    - Sticky headers: scroll down into a date group — the section header stays pinned at the top until the next section pushes it off
    - Chevron animation: tapping a header rotates the chevron smoothly (~200ms)
    - Date labels: "Today" for today, "Yesterday" for yesterday, formatted date for older entries
    - Empty state (only testable with a fresh DB): trophy + "Your wins will live here" copy shown if zero wins
    - No guilt language anywhere on the screen
  </how-to-verify>

  <resume-signal>
    Type "approved" if all 4 success criteria pass.
    Or describe any issues (e.g., "collapse not working", "wrong date label", "chevron not animating") so the executor can fix them before marking Phase 3 complete.
