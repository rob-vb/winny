<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| store → WinsScreen render | wins[] data originates from local SQLite; user's own win text is displayed back to them |
| Win text → Text component | Free-text win content rendered in WinCard; local-only, no XSS surface in React Native |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Information Disclosure | WinsScreen (wins[] render) | accept | Displays user's own local wins to themselves only. No network, no auth surface, no PII sharing. Local-only V1. |
| T-03-05 | Denial of Service | groupWinsByDate useMemo | accept | At 200+ wins, useMemo prevents repeated O(n) transforms on every render. Map-based grouping is O(n). No adversarial input path — data comes from user's own SQLite. |
| T-03-06 | Tampering | collapsedSections state | accept | Local UI state only; affects only visual collapse. No data integrity impact. Resets on re-mount by design (D-15). |
</threat_model>
