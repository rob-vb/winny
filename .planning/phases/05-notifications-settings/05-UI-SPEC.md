## Spacing Scale

Inherited from Phase 1 (unchanged). Multiples of 4 only. Tailwind class names are the implementation contract.

| Token | Value | Tailwind class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | `p-1` / `gap-1` / `m-1` | Icon-to-label gap in settings rows, inline element padding |
| sm | 8px | `p-2` / `gap-2` / `m-2` | Compact spacing, between icon and row label |
| md | 16px | `p-4` / `px-4` / `gap-4` | Default screen horizontal padding, row horizontal padding |
| lg | 24px | `p-6` / `py-6` | Section vertical padding, card inner vertical padding |
| xl | 32px | `p-8` / `mt-8` | Gap between settings sections |
| 2xl | 48px | `p-12` / `mt-12` | Hero area vertical breathing room (not used in this phase) |
| 3xl | 64px | `p-16` | Page-level spacing (not used in this phase) |

**Exceptions:**
- Touch targets: minimum 44px height for all tappable rows and buttons (`min-h-[44px]`). Settings rows must be at least 48px tall in practice (icon + label + value row rhythm).
- Time picker bottom sheet: system-provided (`@react-native-community/datetimepicker` spinner/wheels) — no Tailwind override needed on the picker itself.
- Inline name TextInput focus area: no minimum height override; single-line input, standard 44px row height.

Source: Phase 1 UI-SPEC (spacing scale); Phase 4 UI-SPEC (touch target exceptions pattern).

## Typography

Inherited from the established 4-size, 2-weight scale. No new sizes or weights introduced in Phase 5.

| Role | Size | Weight | Line Height | NativeWind class | Usage |
|------|------|--------|-------------|-----------------|-------|
| Body | 16px (text-base) | 400 (regular) | 1.5 (leading-relaxed) | `font-nunito-regular text-base leading-relaxed` | Row value text, name input text, How It Works body paragraphs, time display value |
| Label | 14px (text-sm) | 700 (bold) | 1.4 (leading-snug) | `font-nunito-bold text-sm leading-snug` | Section header labels, disabled notice text, About row labels |
| Heading | 20px (text-xl) | 700 (bold) | 1.2 (leading-tight) | `font-nunito-bold text-xl leading-tight` | Screen section titles ("Reminders", "Profile", "About"), How It Works screen title |
| Display | 28px (text-[28px]) | 700 (bold) | 1.2 (leading-tight) | `font-nunito-bold text-[28px] leading-tight` | Not used in Phase 5 — slot reserved for consistency with full-app scale |

**Active weights:** regular (400) for all body/value/placeholder text; bold (700) for all section headers, row primary labels, and button labels.

**Row anatomy typography:**
- Row label (left): `font-nunito-bold text-sm text-text-primary` — e.g. "Daily Reminder", "Your Name", "How It Works"
- Row value (right, before chevron): `font-nunito-regular text-base text-text-secondary` — e.g. "8:00 PM", "Rob"
- Section header: `font-nunito-bold text-sm text-text-secondary` — uppercase or standard case, rendered above each section group

Source: Phase 1 UI-SPEC; Phase 4 UI-SPEC; GoalEditor.tsx implementation.

**Additional semantic values in active use:**
- `#1C1C1E` (`text-text-primary`) — row primary labels, section heading text, name field input text

## Interaction Contract

### Reminders Toggle (ToggleRow)

- **ON → OFF:** `setSetting("reminder_enabled", "false")`, call `cancelAll()`. No confirmation dialog.
- **OFF → ON:** `setSetting("reminder_enabled", "true")`. If `notification_permission_status === "granted"`: call `scheduleNext30Days(reminder_time)` immediately. If `"undetermined"`: call `requestPermission()` first, then schedule if granted. If `"denied"`: remain OFF, show disabled notice with Linking.openSettings() affordance.
- **Toggle visual state:** `bg-primary` track when ON; `bg-border` track (or native grey) when OFF.

### Time Picker Row

- **Tap:** Opens `@react-native-community/datetimepicker` in `'time'` mode as a modal bottom sheet (iOS: spinner wheel; Android: clock dialog — use platform default).
- **Select time:** `setSetting("reminder_time", "HH:mm")`, call `scheduleNext30Days(newTime)` (cancel-all + reschedule D-08 in CONTEXT.md). Show inline confirmation below the row: `"Reminders set for {formatted time}"` — `font-nunito-regular text-sm text-text-secondary mt-1`, auto-disappears after 2000ms.
- **Dismiss without selecting:** No change.
- **Disabled state:** `opacity-50` on row when `reminder_enabled === "false"` OR `notification_permission_status === "denied"`. No tap response.

### Display Name (EditableNameRow)

- **Tap row in view mode:** Row transitions to inline edit — label disappears, single-line TextInput appears in place with current name prefilled, `autoFocus={true}`.
- **Blur or Return key press:** `setSetting("display_name", trimmed_value)`. Row returns to view mode showing new name. If name is empty, row shows placeholder "Add your name".
- **No Save button rendered.** Save is implicit on blur/return. No Cancel button. (Different from GoalEditor — this is a single-line field, no modal, no destructive content risk.)
- **Transition:** 200ms Reanimated `withTiming` opacity fade between view and edit states — same pattern as GoalEditor (Phase 4).

### About Row Interactions

| Row | Tap behavior |
|-----|-------------|
| How It Works | `router.push('/settings/how-it-works')` — stack push, back arrow returns to Settings |
| Privacy Policy | `WebBrowser.openBrowserAsync(PRIVACY_URL)` — in-app browser |
| Terms of Use | `WebBrowser.openBrowserAsync(TERMS_URL)` — in-app browser |
| Rate App | `StoreReview.isAvailableAsync()` ? `StoreReview.requestReview()` : `Linking.openURL(APP_STORE_URL)` |
| Share App | `Share.share({ message: SHARE_MESSAGE, url: APP_STORE_URL, title: "Just Keep Winning" })` |

### AppState Top-Up (NOTF-04)

- Listener attached in `app/_layout.tsx` `useEffect` on mount. Unsubscribed on unmount.
- On `AppState` change to `'active'`: call `scheduleNext30Days(reminder_time)` if `reminder_enabled === "true"` and `notification_permission_status === "granted"`.
- No UI feedback — this is a silent background operation.

### Permission Flow (NOTF-01)

- Triggered in `useWinsStore.addWin` after first win save, guarded by `notification_permission_status === "undetermined"`.
- On grant: `setSetting("notification_permission_status", "granted")`, `setSetting("reminder_enabled", "true")`, `setSetting("reminder_time", "20:00")`, `scheduleNext30Days("20:00")`. No UI confirmation — seamless.
- On deny: `setSetting("notification_permission_status", "denied")`. No nag, no retry. Settings Reminders section shows disabled notice.

## State Machine: Settings Screen

| State | Trigger | UI |
|-------|---------|-----|
| `loading` | mount | `SafeAreaView bg-background` — blank (no flash) |
| `ready` | settings loaded from DB | Full sectioned layout rendered |
| `name-editing` | EditableNameRow tapped | Row shows TextInput; all other rows unchanged |
| `picking-time` | TimePickerRow tapped | DateTimePicker modal overlay; rest of screen unchanged |
| `time-confirmed` | picker selection committed | Inline confirmation text below time row, 2000ms |
| `error` | DB load fails on mount | Show load error copy below screen title; all section rows hidden |

---

## State Machine: Notification Service

| State | Condition | Action |
|-------|-----------|--------|
| Never scheduled | `notification_permission_status === "undetermined"` | Await first win → permission prompt |
| Active | `granted` + `reminder_enabled === "true"` | 30 notifications scheduled, AppState top-up active |
| Paused | `granted` + `reminder_enabled === "false"` | All notifications cancelled; queue empty |
| Blocked | `notification_permission_status === "denied"` | No notifications; Settings shows disabled notice |
