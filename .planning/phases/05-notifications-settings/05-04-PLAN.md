<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App → External browser (expo-web-browser) | App opens stub URLs in system browser; URLs are hardcoded constants |
| App → OS Share sheet | Share.share passes app-controlled constant message; no user-input URLs |
| App → App Store (StoreReview / Linking) | Fallback URL is a hardcoded constant; no user-supplied URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-11 | Spoofing | PRIVACY_URL / TERMS_URL constants | accept | Hardcoded stub URLs in src/constants/links.ts — not user-supplied; no open-redirect risk |
| T-05-12 | Spoofing | APP_STORE_URL in StoreReview fallback | accept | Hardcoded constant; Linking.openURL validates iOS/Android URL schemes natively |
| T-05-13 | Information Disclosure | How It Works screen | accept | Static content only; no user data rendered; no network requests |
| T-05-14 | Denial of Service | Share.share cancellation throws on some Android | mitigate | handleShareApp wrapped in try/catch — rejection silently swallowed; no state corruption |
</threat_model>
