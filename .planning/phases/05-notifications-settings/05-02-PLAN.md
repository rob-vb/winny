<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input → settings DB | reminder_time is produced by DateTimePicker (OS-validated, not free text) before being stored via setSetting |
| reminder_time → scheduleNext30Days | HH:mm string is parsed by notificationService; malformed string would produce NaN hours/minutes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-06 | Tampering | reminder_time HH:mm string | mitigate | scheduleNext30Days parses with Number() — NaN results in setHours(NaN) which JS clamps safely; DateTimePicker is the only source so free-text injection is not possible |
| T-05-07 | Denial of Service | scheduleNext30Days called on every toggle | accept | Function is idempotent (cancel-all first); called from UI interaction only; OS rate-limiting applies |
| T-05-08 | Spoofing | Linking.openSettings() | accept | Calls device settings, not a user-supplied URL; no open-redirect risk |
</threat_model>
