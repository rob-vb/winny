  </read_first>

  <action>
  Before triggering builds, run the pre-build sanity check:
    npx jest 2>&1 | tail -5
    npx tsc --noEmit 2>&1 | tail -5

  Both must pass (0 errors). If either fails, do not proceed to builds — fix the error first.

  Then trigger both production builds. These can be submitted to EAS simultaneously (they run in parallel cloud queues):
    eas build --platform ios --profile production --non-interactive
    eas build --platform android --profile production --non-interactive

  The --non-interactive flag prevents prompts. EAS will:
    - For iOS: run CNG, install dependencies, generate Info.plist from app.json, sign with managed certificate + provisioning profile, produce a .ipa
    - For Android: run CNG, install dependencies, generate AndroidManifest.xml from app.json, sign with managed keystore (EAS manages this — no local keystore needed), produce a .aab

  Each build takes ~20–30 minutes. Monitor status at https://expo.dev/accounts/robvb/projects/winny/builds or with:
    eas build:list --platform all --status in-progress

  If either build fails:
    - Check EAS dashboard for error logs
    - Common cause: missing android.package or wrong bundleIdentifier (verify against app.json first)
    - Do not retry until the root cause is identified from the logs
  </action>
