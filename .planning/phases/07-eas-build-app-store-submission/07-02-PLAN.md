<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Physical device — Phase 5 notification + settings verification (D-16)</name>

  <what-built>
  The Phase 5 notification system (deferred from Plan 05-04) and the full Settings screen are implemented. This checkpoint verifies all 8 items from the Phase 5 deferred checklist on a physical iOS device running the new "Winny" EAS dev build built in Task 1.

  The 8 items cover: permission prompt timing (NOTF-01), notification delivery (NOTF-02), rolling 30-day queue (NOTF-03), AppState foreground top-up (NOTF-04), time picker (SET-01), display name persistence (SET-02), About section all 5 rows (SET-03), and no-guilt copy audit.
  </what-built>

  <how-to-verify>
  Install the build from Task 1 on a physical iPhone (EAS QR code or dashboard URL).

  Run all 8 verification items:

  1. NOTF-01 — Permission prompt timing:
     - Cold launch: Home screen appears. Navigate to Settings. Confirm the OS notification permission dialog has NOT appeared yet.
     - Log one win on the Home screen. After tapping the add button, the OS dialog "Winny Would Like to Send You Notifications" (or "Notifications may include alerts...") should appear immediately.
     Expected: Dialog appears exactly once, triggered by the first win save, not by app launch.

  2. NOTF-02 — Notification fires:
     - Grant permission. Go to Settings → Reminder Time. Set it to 2 minutes from now.
     - Lock the screen or background the app. Wait 2+ minutes.
     Expected: Notification arrives with title "Winny" and a body string from the notification copy pool (check notificationService.ts for the pool — no shame/punishment language in any string).

  3. NOTF-03 — Rolling 30-day window:
     - After granting permission, open iOS Settings → Winny → Notifications. This does not show count directly, but confirm notifications are "On" and the app has not crashed.
     - Alternatively: In Xcode Device Organizer or iOS Settings, verify the app does not crash when backgrounded after permission granted.
     Expected: No crash. App continues running silently.

  4. NOTF-04 — AppState foreground top-up:
     - Background the app. Wait 5 seconds. Foreground the app.
     Expected: No crash. No visible change. The notification queue top-up runs silently.

  5. SET-01 — Time picker:
     - Settings → tap "Reminder Time" row.
     Expected: A bottom sheet with a time spinner wheel (iOS) appears. Select a new time. Tap Done.
     Expected: Row value updates to the new time. A brief confirmation toast appears ("Reminders set for HH:MM AM/PM").

  6. SET-02 — Display name persistence:
     - Settings → tap "Your Name" row → text input appears.
     - Type a name. Tap Return or tap elsewhere.
     Expected: Row returns to view mode showing the name.
     - Kill the app and relaunch.
     Expected: Name still shows in Settings.

  7. SET-03 — About section (all 5 rows):
     a. "How It Works" → in-app screen opens with 5 sections. Back arrow returns to Settings.
     b. "Privacy Policy" → in-app browser opens (winny.app/privacy placeholder — expected to show an error page since domain doesn't exist yet; the important thing is the browser opens).
     c. "Terms of Use" → same (in-app browser, winny.app/terms placeholder).
     d. "Rate App" → native App Store review sheet appears (or App Store URL opens if review not available in dev build).
     e. "Share App" → native share sheet appears with "I've been using Winny to log my daily wins..." message.

  8. No-guilt copy audit:
     - Read all 5 notification body strings in src/components/notificationService.ts (or wherever the copy pool lives).
     Expected: No string contains "missed", "forgot", "broke", "failed", "didn't", "bad", "wrong", "shame", or any punishment/guilt framing.

  Also answer these two open questions before resuming (needed for later waves):

  OQ-1 — Play Console account age:
    When was the robvb Google Play Console developer account created?
    - Before November 13, 2023 → no tester gate, can go straight to production after internal test
    - After November 13, 2023 → 12 opted-in testers + 14 continuous days of closed testing required before production access

  OQ-2 — Legal page domain:
    Where will you host the privacy policy and terms pages?
    - winningstreak.app/privacy and winningstreak.app/terms (existing domain)?
    - winny.app/privacy and winny.app/terms (new domain)?
    - Somewhere else?
    The links.ts placeholder currently uses winny.app. The final URL will be set in Plan 07.
  </how-to-verify>

  <resume-signal>Type "approved" or list any failing items and their symptoms. Also include OQ-1 answer (before/after Nov 13 2023) and OQ-2 answer (domain choice).</resume-signal>
