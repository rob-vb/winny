<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Codebase → EAS build cloud | app.json and eas.json are read by EAS to generate native projects; incorrect fields cause permanent bundle ID registration |
| EAS update URL → devices | updates.url determines which EAS Update project serves OTA bundles |
| .gitignore → git history | google-service-account.json must never enter git history |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Information Disclosure | google-service-account.json | mitigate | Add to .gitignore before the file is created; check with `git status` before committing in later plans |
| T-07-02 | Tampering | eas.json submit.production.android.serviceAccountKeyPath | mitigate | Path points to ./google-service-account.json — ensure file is gitignored; do not commit even if accidentally created |
| T-07-03 | Repudiation | EAS managed credentials (iOS cert + Android keystore) | accept | EAS backs up managed credentials automatically; no local keystore needed — do not use `eas credentials --platform android --set-upload-key` with a local keystore |
| T-07-04 | Denial of Service | Wrong runtimeVersion policy ("managed") | mitigate | Use { "policy": "appVersion" } as specified by RESEARCH.md — "managed" causes EAS Build validation failure |
</threat_model>
