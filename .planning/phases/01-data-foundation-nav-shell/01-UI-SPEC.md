## Spacing Scale

NativeWind v4 Tailwind spacing scale — multiples of 4 only.
All values map to standard Tailwind token names used in `className`.

| Token | px value | Tailwind class | Usage |
|-------|----------|---------------|-------|
| xs | 4px | `p-1` / `gap-1` / `m-1` | Icon gaps, tight inline padding |
| sm | 8px | `p-2` / `gap-2` / `m-2` | Compact element spacing, icon-to-label gap in tab bar |
| md | 16px | `p-4` / `gap-4` / `m-4` | Default screen padding, element spacing |
| lg | 24px | `p-6` / `gap-6` / `m-6` | Section padding, card internal padding |
| xl | 32px | `p-8` / `gap-8` / `m-8` | Layout gaps between major sections |
| 2xl | 48px | `p-12` / `gap-12` / `m-12` | Major section breaks, hero area vertical rhythm |
| 3xl | 64px | `p-16` / `gap-16` / `m-16` | Page-level vertical spacing |

**Exceptions:**
- Tab bar touch targets: minimum 44px tall (iOS HIG minimum). Achieved via `Tabs` component defaults — do not override `tabBarStyle.height` below 49px (iOS native default).
- Safe area insets: applied via `react-native-safe-area-context` `SafeAreaView` or Expo Router's built-in inset handling. Do not hard-code safe area values.
- Screen horizontal padding: 16px (`px-4`) applied to all placeholder screen containers.

## Placeholder Screen Contract

```

  └── View (flex-1 items-center justify-center px-4)
        ├── Text (subheading — screen title)
        └── Text (body — coming-soon copy)
```

## Splash Screen Contract

| Property | Value | Notes |
|----------|-------|-------|
| Background color | `#FAF8F4` | Set in `app.json` under `splash.backgroundColor` to prevent white flash |
| Duration | Until `migrationsSuccess && fontsLoaded` both true | Gate in `app/_layout.tsx` using `SplashScreen.preventAutoHideAsync()` |
| Fallback behavior | If migration error: hide splash anyway, log error, do not show blank screen | See RESEARCH.md Pattern 2 |
| Asset | Use Expo's default splash (Phase 1). Trophy mascot splash deferred to Phase 6 (onboarding) | — |

**Critical:** `app.json` must include `"splash": { "backgroundColor": "#FAF8F4" }` to match the warm cream background. Without this, users see a white flash between the OS launch and the app rendering.

## Loading State Contract

| State | What user sees | Duration |
|-------|---------------|----------|
| App launch (DB migrating + fonts loading) | Native splash screen (warm cream `#FAF8F4`) | Until both ready (~200–600ms first launch) |
| Subsequent launches | Native splash screen | Shorter (migrations already applied, fonts cached) |
| DB migration error | Splash hides; log to console; tabs render (empty data state) | Immediate on error |
| Fonts failed to load | Splash hides; tabs render with system fallback font | Immediate on error |

There is no in-app loading spinner for Phase 1. The splash screen is the only loading gate.

## Interaction Contract

### Tab navigation
- **Tap a tab:** Immediate navigation to that tab screen. No animation override — use Expo Router default cross-fade.
- **Tap active tab:** Expo Router default (scroll-to-top if scrollable; no-op if not). Do not customize this in Phase 1.
- **Hardware back (Android):** Expo Router default behavior — exits app from root tab. Do not customize.

### Splash to app transition
- Splash hides with Expo's default `SplashScreen.hideAsync()` fade. Do not add custom animation.
- No navigation occurs — app always opens to the Home tab (index.tsx) on launch.

### Accessibility
- Tab bar icons must have `accessibilityLabel` matching the tab label: `"Home"`, `"My Wins"`, `"Dream Goal"`, `"Settings"`.
- Expo Router's `Tabs.Screen` `title` prop serves as `accessibilityLabel` automatically — no extra prop needed.
- All `Text` elements use semantic font sizes (no `allowFontScaling={false}` — respect user's system font size preference).
