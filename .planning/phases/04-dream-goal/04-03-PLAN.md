```typescript
type GoalState = 'loading' | 'empty' | 'view' | 'editing' | 'saving' | 'error';
```

State transitions (per RESEARCH.md architecture diagram):
- mount → useEffect → getGoal() → null|empty → 'empty'; goal.text present → 'view'
- 'view' + pencil tap → 'editing'
- 'editing' + Save → 'saving' → upsertGoal success → 'view'; error → 'editing'
- 'editing' + Cancel → 'view' (reset currentText to savedText)
- 'empty' + Save → 'saving' → upsertGoal success → 'view'; error → 'empty' (stay)
- getGoal() throws → 'error'
